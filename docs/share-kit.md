## 中文短帖（V2EX / 即刻 / 朋友圈）

写论文、实验报告时，代码从 VS Code 复制到 Word，颜色没了、中文乱了？

开源了个小工具 **码文 / Code for Word**：本机把高亮代码写成 Word 能认的 RTF，粘贴进 Word 格式尽量不乱。Windows 桌面版。

仓库：https://github.com/L00PLeGeNd/code-for-word  
欢迎试用反馈；觉得有用再 Star 就行。

## English short post（Reddit / HN Show / Discord）

I built **Code for Word** — a small Windows app that pastes VS Code–styled code into Microsoft Word as real RTF (colors + CJK stay intact). Aimed at theses, lab reports, and office docs.

https://github.com/L00PLeGeNd/code-for-word

Feedback welcome.
