3.3 训练算法设计

本节给出模型训练的核心流程，算法整体步骤如算法 1 所示。

算法 1: 基于对比学习的联合训练

输入: 训练集 D, 学习率 η, 批大小 B
输出: 收敛的模型参数 θ

1: 初始化参数 θ ← 随机初始化
2: for epoch = 1 to E do
3:     从 D 中采样批数据 {x_i} ← SampleBatch(D, B)
4:     计算对比损失 L ← ContrastiveLoss(θ, {x_i})
5:     更新参数 θ ← θ - η · ∇L
6:     if 验证集精度不再提升 then
7:         提前终止训练
8:     end if
9: end for
10: return θ

算法的收敛性分析见定理 1。

训练过程的时间复杂度为 O(E·N)。
