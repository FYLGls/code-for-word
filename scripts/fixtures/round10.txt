基于混合架构的智能问答系统设计与实现

摘  要

针对传统问答系统在专业领域准确率不足的问题，本文设计并实现了一套基于混合架构的智能问答系统。
系统融合了**检索增强生成**与知识图谱两种技术路线，并针对中文场景进行了优化。
在自建测试集上的实验表明，系统回答准确率达到 92.4%，较基线提升 __7.8 个百分点__。

关键词：智能问答；检索增强；知识图谱

Abstract

This paper presents an intelligent question answering system with a hybrid architecture.
The system combines retrieval-augmented generation with a knowledge graph.
Experiments show an accuracy of 92.4% on our benchmark.

Key words: question answering; RAG; knowledge graph

第1章 绪论

1.1 研究背景

问答系统是自然语言处理的核心应用之一。
早期系统基于模板匹配，覆盖面有限。
近年来，大语言模型的发展为该领域带来了新的范式。

1.2 主要挑战

- 领域知识更新滞后
- 生成内容存在幻觉
- **推理成本**居高不下

第2章 系统设计

2.1 总体架构

系统采用前后端分离架构，核心检索接口实现如下：

```python
def 检索(query, top_k=5):
    """向量检索并重排序"""
    vec = encoder.encode(query)
    hits = index.search(vec, top_k * 3)
    reranked = reranker.score(query, hits)
    return reranked[:top_k]
```

前端路由配置为：

const routes = [

1: for 文档 in T do
2:     实体 ← NER(文档)

第3章 实验分析

3.1 实验设置

测试集包含 2000 个专业领域问题，答案由三位标注员交叉审核。

3.2 实验结果

各方法对比如下：

（1）纯生成式基线准确率为 76.5%。
（2）纯检索式基线准确率为 81.2%。
（3）本文混合方法准确率为 92.4%。
